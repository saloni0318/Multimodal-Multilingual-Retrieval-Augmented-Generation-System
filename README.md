# 🌍 Multimodal Multilingual RAG System

![Python](https://img.shields.io/badge/Python-3.12-blue)

![Ollama](https://img.shields.io/badge/LLM-Ollama-orange)
![Qdrant](https://img.shields.io/badge/VectorDB-Qdrant-red)

A RAG (Retrieval Augmented Generation) system that lets you ask questions about PDF documents in **any language** — including Hindi, Malayalam, Tamil, Hinglish, Arabic, and 100+ more. Unlike most RAG systems that only handle English text, this one understands text, tables, and images/charts inside PDFs, and answers in the same language you ask in.

Everything runs **100% locally** on your machine. No OpenAI API, no paid services, no internet required after setup.

---

## 🏗️ How It Works

When you upload a PDF, the system splits it into three types of content — text blocks, table rows, and images. Each image is sent to LLaVA (a free vision model) which describes what it sees in detail. All three content types are then converted into vectors using `multilingual-e5-large`, a free embedding model that maps 100+ languages into the same mathematical space.

When you ask a question, your query is embedded using the same model and matched against stored vectors in Qdrant. The most relevant chunks — whether text, table, or image description — are passed to Gemma3 (running locally via Ollama), which generates an answer in the same language as your question.

---

## ✨ What Makes This Different

Most RAG projects on GitHub wrap OpenAI's API and only support English. This project is different in three ways. First, it handles **mixed-language queries** like Hinglish ("Is paper mein algorithm kaise kaam karta hai?") or Manglish ("Algorithm എങ്ങനെ work cheyyunnu?") naturally, because `multilingual-e5-large` was trained on real internet text full of code-switching. Second, it understands **images and charts** — LLaVA captions every figure so you can ask "explain the chart on page 3" and get a real answer. Third, it runs **entirely offline** with zero API costs.

| Component | Tool |

| LLM | Gemma3 via Ollama |
| UI | Gradio |

## 🚀 Setup

**1. Clone and install**
```bash
git clone https://github.com/saloni0318/Multimodal-Multilingual-Retrieval-Augmented-Generation-System.git
cd Multimodal-Multilingual-Retrieval-Augmented-Generation-System
pip install -r requirements.txt
```

**2. Pull Ollama models** (install Ollama from https://ollama.com first)
```bash
ollama pull llava
ollama pull gemma3
```

**3. Launch**
```bash
python ui/app.py
```
Open **http://127.0.0.1:7860** in your browser.

---

## 🖥️ How to Use

Upload any PDF using the upload button, then wait for processing. The system will extract text and images, caption every figure using LLaVA, and embed everything into the vector store. Once done, type your question in any language and get a cited answer with source page numbers.

## ⚙️ Configuration

All settings live in `src/config.py`. Key options:

```python
EMBED_MODEL_NAME  = "intfloat/multilingual-e5-large"
LLM_MODEL         = "gemma3"
VISION_MODEL      = "llava"
CHUNK_SIZE        = 512
TOP_K             = 6
USE_MEMORY_QDRANT = True   # set False for persistent storage
```
